# 재림마을 리디자인 컨셉

제칠일안식일예수재림교 한국연합회의 회원 포털 [재림마을(adventist.or.kr)](https://www.adventist.or.kr)을
**기존 기능은 모두 유지하면서, 전 연령이 쓰기 쉽고 신뢰감 있는 기관 사이트**로 다시 설계한 개인 포트폴리오 작업입니다.

> **비공식 컨셉입니다.** 한국연합회나 재림마을 운영센터와 무관하며, 기사 본문·수치·인명은 샘플입니다.
> 실제 서비스는 [adventist.or.kr](https://www.adventist.or.kr)에서 이용하세요.

- **라이브 시안:** https://kimmoksan.github.io/adventist-portal-redesign/
- **소스:** [`index.html`](index.html) — 빌드 없이 열리는 단일 파일 (HTML · CSS · 바닐라 JS)

## 무엇을 바꿨나

| 기존 사이트의 문제 | 리디자인에서의 해결 |
|---|---|
| 한 화면에 위젯 30여 개가 밀집해 어디부터 봐야 할지 모름 | 오늘의 말씀 → 자주 찾는 서비스 → 뉴스 → 방송 → 신앙·성경공부 → 지역교회·연합회 → 커뮤니티 순으로 우선순위 정리 |
| 작은 글씨와 약한 대비, 어르신에게 불리 | 본문 17px 이상, 글자 크기 3단계 조절, 주요 색 대비 AA 이상, 터치 영역 48px |
| 매일 쓰는 교과·기도력 동선이 구석에 있음 | 첫 화면 오른쪽에 날짜 기준 "오늘의 말씀" 패널 고정 |
| 80여 개 하위 메뉴를 찾기 어려움 | 8개 대메뉴 아래로 전체 하위 메뉴가 한 번에 펼쳐지는 메가메뉴, 모바일 아코디언 전체메뉴 |

## 화면 구성

- **헤더** — 공식 마크 + 교단명 + 재림마을 워드마크(기준선 정렬), 통합검색, 로그인·회원가입·사이트맵, 글자 크기
- **주 메뉴 띠** — 스크롤 시 상단 고정, 호버/포커스 시 하위 메뉴판이 슬라이드로 내려오고 해당 열만 강조
- **메인 비주얼** — 7초마다 크로스페이드로 넘어가는 주요 소식, 제목 탭과 진행 표시, 일시정지 버튼, 호버·포커스 시 자동 정지
- **오늘의 말씀** — 장년교과 · 장년기도력 · 어린이기도력 · 오늘의 성경 구절
- **자주 찾는 서비스** — 성경, 찬미가, 안교교과, 예언의 신, 기도력, 교회주소록, 성경공부 신청, 재림성경
- **뉴스** — 분류 탭, 대표 기사 3건이 6초마다 순환, 분류 태그가 붙은 목록, 공지사항·행사안내
- **방송 · 신앙과 생활 · 성경공부 · 선교 · 지역교회 · 한국연합회 · 커뮤니티(구인·구직·알뜰시장·부고) · 공감기도**
- **가까운 재림교회 찾기**, 기관·합회 바로가기, 앱·SNS, 푸터

## 설계 원칙

1. **오늘이 첫 화면이다.** 날짜에 맞춰 매일 찾는 교과·기도력이 가장 먼저 보인다.
2. **모든 기능은 한 단계 안에, 홈은 우선순위만.** 전체 사이트맵은 메가메뉴로 언제나 한 번에 닿는다.
3. **75세 성도가 휴대폰에서 확대 없이 읽고, 어린이도 쓸 수 있게.**
4. **CI는 스티커가 아니라 시스템.** 재림교회 공식 CI(대총회 시각디자인 체계)의 마크와 색을 기준으로 하고, 화면 가독성을 위해 주조색 명도만 보정했다(공식 Denim `#2f557f` → 화면용 `#2861ab`).
5. **샘플은 샘플이라고 표시한다.** 교회에 대한 사실이나 수치를 지어내지 않는다.

## 접근성

- 본문 바로가기, 모든 조작 요소에 `:focus-visible` 표시
- 메가메뉴 키보드 조작(Tab 진입, Esc 닫기 후 포커스 복귀), 탭은 방향키 이동과 ARIA 역할
- 자동 넘김은 일시정지 가능하고, 호버·포커스·탭 숨김 시 멈추며, `prefers-reduced-motion` 사용자에게는 자동으로 넘기지 않음
- 글자 크기 설정은 브라우저에 저장(실패해도 페이지는 정상 동작)
- 375px부터 1440px까지 가로 스크롤 없음

## 작업 방식

- 기존 사이트의 전체 메뉴 구조와 실제 게시물 제목을 수집해 정보 구조의 기준으로 삼음
- 5가지 방향(공식 포털, 오늘 일정판, 교단 뉴스룸, Creation Grid 브랜드, 찾기 허브)을 홈 전체 수준으로 시안화한 뒤 **공식 포털형**을 선택해 발전
- Claude Code와 OpenAI Codex를 함께 사용해 시안을 병렬 제작하고, 브라우저 렌더링 검증과 디자인 품질 검사(impeccable)를 거쳐 다듬음
